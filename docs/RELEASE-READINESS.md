# M10 发布就绪与测试矩阵

本表把自动门禁与必须在真实设备上执行的发布前检查分开。仓库 CI 不构建、签名或发布移动应用；真机项由具备设备与签名环境的发布负责人执行并附证据。

## 自动门禁

| 范围 | 门禁 | 覆盖 |
|---|---|---|
| Contracts | Vitest、生成物一致性 | REST/WS Schema、共享等级、非法输入 |
| Worker | Vitest、SQLite D1 集成、TypeScript、ESLint | 权限、房间生命周期、近似位置、断线清除、Twin 删除、PMTiles、脱敏日志 |
| Web | Vitest、Playwright Chromium/Firefox/移动视口、构建预算 | 隐私默认值、客户端脱敏报告、双客户端协议与桌面/移动布局旅程 |
| Flutter | `flutter analyze`、`flutter test`、架构校验 | 状态、协议解析、权限策略、PulseTown 逻辑；不执行应用编译 |
| 数据 | 确定性构建差异、manifest/PMTiles/导航校验 | 稳定 ID、共享地点、路网和瓦片完整性 |

Playwright 的双客户端旅程使用严格的 REST/WSS mock 隔离浏览器交互；真实 Worker 的鉴权、Durable Object 多连接、请求去重、Pin 并发与 SQLite D1 级联删除由 `apps/worker/test` 的集成测试覆盖。两层都通过才可合并，不能把浏览器 mock 结果单独视为后端验收。

## 发布前真机矩阵

| 平台/网络 | 场景 | 通过标准 | 状态 |
|---|---|---|---|
| Android 当前稳定版 / Wi-Fi | 首次拒绝定位、稍后授权、开始模糊共享、暂停 | 未授权不读取；模糊共享无精确字段；暂停立即停止 | 待真机签署 |
| Android 当前稳定版 / 4G | 两台设备同房间、断网 10 秒、恢复 | 连接状态可见；恢复后快照一致；不重复 Pin | 待真机签署 |
| Android 当前稳定版 / 弱网 | 1 Hz 位置更新、锁屏/解锁、前后台切换 | 无消息风暴；后台策略符合系统权限；位置不落盘 | 待真机签署 |
| iOS 当前稳定版 / Wi-Fi | 同 Android 权限与共享场景 | 权限说明明确；停止/断开后成员位置消失 | 待真机签署 |
| iOS 当前稳定版 / 4G | 两台设备重连与房间到期 | 最终一致；到期停止共享；无过期内容访问 | 待真机签署 |
| iOS 当前稳定版 / 弱网 | 锁屏、旋转、低电量模式 | 无崩溃；卡顿上报不含错误内容；电量消耗可接受 | 待真机签署 |
| Android/iOS / 任意 | PulseTown 与地图模式往返、Twin 开关 | GPS 与模拟位置视觉/协议区分；关闭后日程与计划删除 | 待真机签署 |

每次候选版本至少记录设备型号、OS 版本、网络、构建 SHA、开始/结束时间、结果和缺陷链接。任何权限误导、精确位置泄露、断开后继续共享、数据无法删除或房间越权均为发布阻断项。
